# 3D 检索背景实现说明

## 实现范围

参考用户提供的 Vault 截图，实现悬浮珍珠球体、地面波纹和浅灰空间。当前代码是按视觉参考编写的 Three.js 场景，并非原站源码或原站素材。首页直接提供检索，统计与综述保留在下方。

## 实现思路

1. `static/scene.js` 独立管理场景，`static/scene.css` 管理首页布局。背景初始化失败不会阻塞检索接口。
2. 球体采用 Three.js 球面几何体。顶点着色器做小幅形变，片元着色器根据表面朝向计算高光、边缘反光和细微珠光纹理。这是轻量的艺术化材质，不是完整物理光照模拟。
3. 地面使用平面几何体，按到中心的距离计算正弦波纹、衰减和接触阴影。球体起伏与波纹共用动画时间。
4. 鼠标位置控制球体轻微转动，按钮可以暂停。开启系统“减少动态效果”时默认静止；离开首屏或切换标签页时停止连续渲染。
5. 像素比限制为 1.5，避免高分屏渲染成本过高。手机调整相机距离和球体位置，保证检索控件可见。WebGL 不可用时保留浅灰背景和检索功能。

## 本地依赖

Three.js 固定为 0.170.0，文件位于 `static/vendor/three.module.js`，MIT 许可证保留在同目录 `THREE-LICENSE.txt`。动画无远程模型、贴图或 CDN 请求。原有统计图表仍使用原项目的 ECharts CDN。

## 验证

- Playwright 检查 1440×960 和 390×844 两种视口，截图确认构图；像素差异确认画面非空且随时间变化。
- 检查暂停后画面不变、减少动态效果默认暂停、页面无横向溢出和脚本错误。
- 后端现有 14 项单元测试通过。浏览器业务回归使用本地文献样本和模拟 AI 失败，避免为背景改动调用付费模型。

## 可调参数

- 球体大小与细分数：`SphereGeometry`。
- 珠光、高光和波纹：两个 `ShaderMaterial` 的片元着色器。
- 起伏速度与幅度：`draw()`。
- 桌面和手机构图：`resize()`；首屏尺寸：`scene.css` 中 `.search-stage`。

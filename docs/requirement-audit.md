## IF 实现思路与边界

- IF 是期刊指标，不是单篇文献的被引量或影响力评分。原图中的“影响因子”不能用 CiteScore、SJR 或估算值替代。
- 默认快照为 2025 指标年；用户导入表整体优先，避免把演示数值或不同年份默默混入排名。来源 URL 与年份显示在每条文献旁。
- 已修复旧算法以结果最大年份为“现在”的错误；普通排序采用当前年及前四年，并排除未来年份。独立检索进一步用 PubMed 日期查询限制到当天。
- 独立 Top 100 按已知期刊 IF 降序查询，同一期刊分页获取文献，按 PMID 去重。已有 100 篇合格文献时，更低 IF 期刊不能进入前 100，可停止检索。分界处相同 IF 可有多篇并列，本次返回其中 100 篇，不宣称穷尽所有并列文献。
- PubMed 单查询 10000 条上限、缺失 XML 记录、指标匹配冲突等会标为范围内不完整，不用 Mock 填充真实排名。
- `global_complete` 固定为 false：没有完整 IF 来源，不能证明全 PubMed 前 100。`ranking_complete_within_table` 仅描述本表范围，不代表全量数据。

## 本轮验证

- 28 项单元测试通过，覆盖年份边界、100 篇独立排序、去重、未匹配数据、故障无 Mock 排名、原有导入和解析功能。
- 真实 `cancer` 检索：100 篇、不重复、年份均在 2022–2026，IF 非递增；本次同为 118.0，来自最高 IF 已收录期刊，属于并列结果。
- 真实 `diabetes` 普通检索 20 篇：仍匹配 3 篇（15%）；本轮新增记录没有出现在 PubMed 当前相关性排序的 20 篇中。这说明指标覆盖必须按实际关键词验收，不能用快照条数作为最终验收标准。
